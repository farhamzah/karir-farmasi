# SAFA KARIR — Farmasi UBP

Fondasi lokal portal alumni dan karier Fakultas Farmasi UBP untuk target `karir.safaubp.com`.

Stack: Laravel 13, React, TypeScript, Inertia, dan MySQL 8.x. Login Core live dan modul bisnis belum aktif. Identity gateway default menolak akses sampai kontrak integrasi resmi tersedia; fixture hanya untuk local/testing dengan data sintetis.

Runtime development menggunakan PHP dan MySQL portable khusus aplikasi tanpa mengubah XAMPP, PATH global, Docker/WSL, atau aplikasi lain. Lihat `ops/RUNBOOK.md`.

Repository lokal berada pada branch `codex/skr-001-foundation`, tanpa commit atau remote. Remote masa depan yang dicatat Owner: `https://github.com/farhamzah/karir-farmasi.git`.
